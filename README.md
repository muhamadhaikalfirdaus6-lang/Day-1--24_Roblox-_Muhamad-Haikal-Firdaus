## Dokumentasi Kegiatan Workshop (Day 1)

### 1. Rangkuman Materi
* Sepemahaman saya terkait materi workshop yang telah di lakukan adalah bagaimana cara merancang instruksi yang tepat agar AI memberikan jawaban yang relevan dan langsung bisa digunakan. Prompt ini bisa berupa pertanyaan sederhana hingga instruksi kode yang rumit. Kemudian ada juga pemaparan terkait Struktur Prompt yang Baik. Struktur prompt yang baik itu harus mengandung unsur Role (Peran AI), Task (Tugas utama), Context (Konteks/Detail latar belakang), dan Format (Bentuk output yang diinginkan).
* Ada juga  yang saya dapat pada materi seminarnya adalah perbedaan antara Git dan GitHub. Jadi **Git** adalah sebuah sistem lokal untuk melacak dan mencatat setiap perubahan yang terjadi pada file proyek (siapa, kapan, dan apa yang diubah). Sedangkan **GitHub** adalah platform berbasis web (online) untuk menyimpan repositori Git agar bisa diakses di internet dan mempermudah kolaborasi antar tim.
* Kemudian terkait alur kerja Git (Git Workflow) yang terdiri dari Working Directory (tempat edit kode di komputer), Staging Area (tempat mengumpulkan file yang siap disimpan), dan Git Directory/Repository (tempat penyimpanan permanen riwayat perubahan).

### 2. Poin-Poin Penting & Pengetahuan Baru
* **Pentingnya Konteks dalam Prompting**, dari sini saya mendapat pengetahuan baru terkait membuat prompt yang baik dengan terstruktur serta memberikan konteks atau batasan yang lebih jelas.
* **Perbedaan Mendasar Git vs GitHub**, dari sini pula saya mendapat gambaran terkait perbedaan antara Git dan GitHub serta kegunaannya masing masing.
  

### 3. Pendapat Pribadi tentang Day 1 Proyek Workshop
* Menurut saya, seminar ini memberikan fondasi yang sangat kuat bagi mahasiswa atau pemula dalam memahami pentingnya keteraturan dalam menulis kode. Selama ini saya sering kesulitan melacak file tugas ngoding yang versinya berubah-ubah di komputer. Melalui seminar ini, saya sadar bahwa kombinasi instruksi AI yang terstruktur (Prompt) dan sistem pelacak perubahan (Git) adalah kunci agar proyek kita tidak berantakan.
